Variant Matrix

The same five statuses are shown in both themes (`color` and `white`) and in both directions.

LTR - Color

Success title

When successful actions need direct feedback, show it here.

Warning title

Use warning to clarify risks before user confirmation.

Destructive title

This action cannot be undone once submitted.

Info title

Informational messages can provide context and next steps.

Neutral title

Use neutral for generic notices that are not status-critical.

LTR - White

Success title

White theme can be used on dense pages to reduce visual weight.

Warning title

Use with supporting text and optional actions.

Destructive title

You can combine this with action buttons below.

Info title

Use info for guidance and non-blocking updates.

Neutral title

Neutral white is useful for generic inline announcements.

RTL - Color

عنوان التنبيه

يدعم النظام الاتجاه من اليمين إلى اليسار بشكل كامل.

RTL - White

عنوان التنبيه

Usage Snippet

Use this minimal structure in your pages.

<div class="dga-alert" data-variant="info-white">
  <span class="dga-alert-icon" aria-hidden="true"></span>
  <div class="dga-alert-content">
    <h4 class="dga-alert-title">Notification/Alert message title</h4>
    <div class="dga-alert-body">
      When a Notification/Alert needs a further detailed explanation, it goes here.
    </div>
    <div class="dga-alert-actions">
      <button class="dga-btn dga-btn-primary dga-btn-sm">Button</button>
      <button class="dga-btn dga-btn-secondary-outline dga-btn-sm">Button</button>
    </div>
  </div>
  <button class="dga-alert-close" type="button" data-alert-close aria-label="Dismiss alert">×</button>
</div>
